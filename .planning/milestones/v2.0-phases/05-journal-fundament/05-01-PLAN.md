2. Tabelle per `CREATE TABLE IF NOT EXISTS` anlegen:

   | Spalte | Typ | Bedeutung |
   |---|---|---|
   | `id` | INTEGER PK AUTOINCREMENT | |
   | `userId` | INTEGER NOT NULL | FK users, ON DELETE CASCADE |
   | `year` | INTEGER NOT NULL | Urlaubsjahr, auf das gebucht wird |
   | `date` | TEXT NOT NULL | Datum der Buchung (YYYY-MM-DD) |
   | `type` | TEXT NOT NULL | CHECK: siehe Schritt 3 |
   | `days` | REAL NOT NULL | positiv = Gutschrift, negativ = Belastung |
   | `description` | TEXT | lesbare Begründung (REQ-04) |
   | `referenceType` | TEXT | CHECK IN ('absence','manual','system', NULL) |
   | `referenceId` | INTEGER | z. B. `absence_requests.id` |
   | `balanceBefore` | REAL | Saldo vor der Buchung |
   | `balanceAfter` | REAL | Saldo nach der Buchung |
   | `createdAt` | TEXT DEFAULT (datetime('now')) | |
   | `createdBy` | INTEGER | FK users — wer die Buchung ausgelöst hat (REQ-04) |

3. CHECK-Constraint auf `type` mit genau diesen sechs Werten (REQ-02):
   `entitlement`, `carryover`, `vacation_taken`, `vacation_reverted`, `correction`, `expiry`

   Begründung der Wahl: `vacation_taken` und `vacation_reverted` bilden Genehmigung und Storno
   als getrenntes Paar ab — genau die Bewegung, deren Fehlen den Datenverlust verursacht hat.
   Ein einzelner Typ mit Vorzeichen würde die Unterscheidung verwischen.

4. Indizes anlegen (Lesepfade sind: Konto eines Nutzers pro Jahr, und Buchungen zu einem Antrag):
   - `idx_vacation_tx_user_year` auf `(userId, year)`
   - `idx_vacation_tx_reference` auf `(referenceType, referenceId)`

5. **Selbstverifikation am Ende der Migration** (Lehre aus Migration 003): Prüfen, dass die
   Tabelle existiert und alle erwarteten Spalten hat. Wenn nicht → `throw`, damit die Migration
   NICHT als erledigt markiert wird.

   ```ts
   const cols = db.prepare(`PRAGMA table_info(vacation_transactions)`).all() as Array<{name: string}>;
   const expected = ['id','userId','year','date','type','days','description',
                     'referenceType','referenceId','balanceBefore','balanceAfter',
                     'createdAt','createdBy'];
   const missing = expected.filter(c => !cols.some(x => x.name === c));
   if (missing.length) throw new Error(`Migration 007 unvollständig, fehlende Spalten: ${missing.join(', ')}`);
   ```
  </steps>
